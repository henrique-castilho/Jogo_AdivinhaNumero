# LeitorDePensamentos

## Descrição
Aplicação Java Swing simples que “pensa” em um número entre 1 e 10 e permite que o usuário tente adivinhar em até 3 tentativas. Interface criada com NetBeans.

## Funcionalidades

- Gera um número aleatório entre 1 e 10.
- Interface gráfica com `JSpinner` para inserir palpites.
- Botões para enviar palpite (`Palpite`) e reiniciar o jogo (`Reniciar`).
- Feedback textual: acerto, dica (maior/menor) ou fim das tentativas.

## Pré-requisitos

- JDK 8 ou superior instalado.
- NetBeans (opcional, recomendado, pois o projeto foi gerado com ele).

## Executando pelo NetBeans (recomendado)

1. Abra o projeto no NetBeans (pasta do projeto com `nbproject`).
2. Execute pelo botão Run da IDE.
